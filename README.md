# Lead Finder

Помощник для поиска клиентов на создание сайтов и лендингов: база малого бизнеса
(кафе, автосервисы, магазины, салоны…), которому нужен сайт.

Компании ты находишь сам в 2ГИС и Яндекс Картах и за пару секунд сохраняешь в свою базу.
Программа работает только на твоём компьютере: http://localhost:3001.

## Как запустить

1. Нужен Node.js версии 22.13 или новее (проверить: `node --version`).
2. Дважды кликни **`start-leads.cmd`**. Откроется чёрное окно сервера, а через 2 секунды —
   страница в браузере.
3. Пока программа нужна, окно сервера не закрывай. Чтобы остановить — закрой окно
   (или нажми в нём Ctrl+C).

Если запустить второй раз, пока первое окно открыто, программа напишет, что порт 3001 занят, —
просто пользуйся уже открытой страницей.

Запуск из терминала (то же самое): `npm start`.

## Что умеет сейчас (этап 1)

- Форма «Добавить компанию»: название (обязательно), сфера (подсказки + свой вариант), город,
  адрес, ссылка на карточку 2ГИС / Яндекс Карт, рабочий телефон, сайт или соцсеть, рейтинг,
  число отзывов, заметка.
- Источник (2ГИС / Яндекс Карты / другое) и ID организации определяются по ссылке автоматически.
  Короткие ссылки (`go.2gis.com/…`, `yandex.ru/maps/-/…`) не раскрываются — у них просто нет ID.
- Телефон приводится к виду `+7XXXXXXXXXX` (`8 (916) 123-45-67` → `+79161234567`).
- Защита от дублей. Компания считается уже сохранённой, если:
  1. совпадает ID организации из ссылки (та же карточка 2ГИС или Яндекса), **или**
  2. совпадают название и телефон (так ловится та же компания из другой карты), **или**
  3. телефона нет — совпадают название и адрес; если нет и адреса — только название.

  Название и адрес сравниваются без учёта регистра, кавычек, лишних пробелов и «ё/е».
- Таблица сохранённых компаний, новые сверху. На телефоне строки превращаются в карточки.
- После сохранения город и сфера остаются в форме — удобно добавлять подряд компании
  из одного города и одной сферы.

## Правила, которые программа соблюдает

- **Не заходит на сайты 2ГИС и Яндекс Карт** и ничего оттуда не скачивает. Данные о компаниях
  попадают в программу только от тебя.
- На следующих этапах будет обращаться только к собственным сайтам компаний: 1 запрос
  на главную страницу, с таймаутом и паузой между сайтами.
- Не делает рассылок: тексты предложений ты отправляешь сам, каждому лично.
- Хранит только данные компании (название, сфера, адрес, рабочий телефон, сайт/соцсети,
  ссылка на карточку, рейтинг). Никаких личных данных сотрудников и авторов отзывов.

## Где хранятся данные

- База — файл `data/leads.db` (SQLite). Он создаётся при первом запуске.
- **Резервная копия:** останови программу и скопируй файл `data/leads.db` в надёжное место.
- Когда новая версия программы меняет структуру базы, она сначала сама кладёт копию
  в `data/backups/`.
- Папка `data/` и файл `.env` (будущие ключи API) не попадают в git — см. `.gitignore`.
  Образец для ключей — `.env.example`.

## Тесты

```
npm test
```

Проверяется: добавление компании, отказ без названия, нормализация телефона, дубли
(по ID из ссылки, по названию + телефону, по названию + адресу), разбор ссылок 2ГИС
и Яндекса, обновление структуры базы без потери данных, работа сервера и API.

## Как устроен проект

```
start-leads.cmd        запуск двойным кликом
src/main.js            точка входа: открывает базу, запускает сервер на 127.0.0.1:3001
src/server.js          веб-сервер: отдаёт страницу и отвечает на /api/companies
src/companies.js       список компаний, добавление, поиск дублей
src/db.js              открытие базы и миграции (+ резервная копия перед ними)
src/migrations.js      пронумерованные изменения структуры базы
shared/normalize.js    телефон, ссылки, определение 2ГИС/Яндекса — общий код для сервера и страницы
shared/validate-company.js  проверка полей формы — тоже общая
public/                страница: index.html, style.css, app.js
test/                  автотесты (node:test)
```

Только встроенные модули Node.js, без npm-пакетов: `node:http`, `node:sqlite`, `node:test`.

API (для любопытных):

- `GET /api/companies` → `{ companies: [...] }`
- `POST /api/companies` (JSON) → `201` сохранено, `400` ошибки в полях, `409` дубль

## План

1. ✅ Каркас и ручное добавление компаний
2. Быстрая вставка текста карточки → программа сама находит телефоны и ссылки

5. Статусы работы с клиентом, даты, заметки, фильтры, экспорт в CSV
6. Черновик персонального предложения + «Скопировать»
7. Импорт CSV/Excel, возможно — официальный API 2ГИС
